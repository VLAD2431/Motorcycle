# Пассажир и движение гравибайка без водителя

Согласовано пользователем 2026-11-24.

## Цель

Пассажир остаётся на заднем месте после выхода водителя. Байк продолжает движение по инерции и постепенно замедляется.

## Подходы

Выбран точечный подход: удалить автоматическое повышение пассажира до водителя и использовать существующие расчёты горизонтальной скорости, столкновений, рельефа и прыжка для байка без водителя. Отдельный движок инерции дублировал бы физику; простое сохранение velocity обходило бы существующую обработку препятствий.

## Поведение

- Убрать пересадку при выходе, принудительном снятии, посадке другого игрока и в основном цикле.
- Разрешить новому игроку занимать свободное водительское место при занятом пассажирском.
- Без водителя сохранять направление и уменьшать скорость существующим rolling resistance до нуля, в том числе при движении назад.
- Сохранить обработку препятствий и рельефа, завершать начатый прыжок без запуска новых.
- Сохранить ограничения запретных зон и хранения; пассажир не управляет байком.

## Ограничения и проверка

Paper API 1.21+, Java 21, Maven. Без новых зависимостей, настроек, изменения хранения данных и постороннего рефакторинга. Регрессионные тесты JUnit/Mockito; проверка `mvn test-compile` и `mvn test`. Игровые сценарии дополнительно проверяются на Paper-сервере.
