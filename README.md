# Motorcycle Plugin

Paper-плагин для Minecraft 1.21+, добавляющий управляемый электрический гравибайк с физикой движения, батареей, визуальной моделью из ресурс-пака, частицами поверхности, звуками и зонами ограничений.

## Возможности

- Установка гравибайка предметом через ПКМ.
- Посадка игрока на мотоцикл и управление скоростью и поворотом.
- Ускорение, торможение, движение назад, прыжок и парение над поверхностью.
- Проверка препятствий, ступенек, свободного места и поверхности под байком.
- Поддержка воды как поверхности движения.
- Заряд батареи, расход энергии и отображение заряда в action bar.
- Уборка мотоцикла обратно в инвентарь клавишей смены рук (`F`).
- Частицы песка, красного песка и воды при движении.
- Звуки холостого хода и несколько диапазонов скорости.
- Зоны `no_ride` для запрета езды и `charge` для зон зарядки.
- Опциональная интеграция с WorldGuard.
- SQLite-хранилище зон с режимом WAL.
- Сервисный API для изменения внешнего вида предметов гравибайка.

## Требования

- Java 21.
- Paper 1.21 или новее.
- WorldGuard 7.0.14 или совместимая версия — только для интеграции с WorldGuard; базовая работа плагина от него не зависит.
- Ресурс-пак — если нужна собственная 3D-модель или собственные звуки.

## Установка

1. Соберите плагин или скачайте готовый `Motorcycle.jar`.
2. Поместите файл в папку `plugins/` сервера Paper.
3. При необходимости установите WorldGuard.
4. Запустите сервер один раз, чтобы плагин создал `config.yml` и папку данных.
5. Настройте `plugins/MotorcyclePlugin/config.yml`.
6. Перезапустите сервер либо выполните `/moto reload` с правом `motorcycle.admin`.

Готовый JAR создаётся Maven в папке `target/` под именем `Motorcycle.jar`. Файлы из `target/` не являются исходниками и не должны добавляться в Git.

## Использование

Администратор выдаёт игроку предмет гравибайка:

```text
/moto give <игрок>
```

Предмет устанавливается ПКМ. Для уборки нужно находиться рядом с байком, нажать клавишу смены рук (`F`) и не двигаться во время процесса. Уборка может быть отменена получением урона, если это включено в конфигурации.

Во время движения в action bar отображаются заряд батареи и скорость. Заряд расходуется при движении и восстанавливается в зоне типа `charge`.

## Команды

Основная команда — `/moto`. Доступен также алиас `/motorcycle`.

| Команда | Назначение | Право |
|---|---|---|
| `/moto give <игрок> [количество]` | Выдать от 1 до 64 предметов гравибайка | `motorcycle.give` |
| `/moto pos1` | Установить первую точку зоны в текущей позиции | `motorcycle.admin` |
| `/moto pos2` | Установить вторую точку зоны в текущей позиции | `motorcycle.admin` |
| `/moto zone create <no_ride\|charge> <имя>` | Создать зону по двум выбранным точкам | `motorcycle.admin` |
| `/moto zone delete <имя>` | Удалить зону | `motorcycle.admin` |
| `/moto zone list` | Показать список зон и их типы | `motorcycle.admin` |
| `/moto reload` | Перезагрузить конфигурацию мотоцикла | `motorcycle.admin` |
| `/moto` | Показать справку по командам | зависит от прав |

Для создания зоны:

1. Выполните `/moto pos1` в первой точке.
2. Выполните `/moto pos2` во второй точке.
3. Выполните `/moto zone create no_ride <имя>` или `/moto zone create charge <имя>`.

Имя зоны может содержать только латинские буквы, цифры, `_` и `-`, длина — от 1 до 32 символов. Обе точки должны находиться в одном мире.

## Права

| Право | По умолчанию | Назначение |
|---|---|---|
| `motorcycle.give` | OP | Выдача гравибайков |
| `motorcycle.admin` | OP | Выбор точек, управление зонами и перезагрузка |

## Конфигурация

Основной файл — `plugins/MotorcyclePlugin/config.yml`. Наиболее важные группы:

| Раздел | Что настраивает |
|---|---|
| `motorcycle.item` | Материал предмета, MiniMessage-название, lore, модель и custom model data |
| `motorcycle.water` | Разрешение движения по воде |
| `motorcycle.particles` | Частицы для песка, красного песка и воды |
| `motorcycle.physics` | Скорость, ускорение, торможение, повороты, прыжок и парение |
| `motorcycle.collision` | Габариты и дополнительный радиус столкновений |
| `motorcycle.visual` | Смещения, повороты, наклоны, масштаб и интерполяция модели |
| `motorcycle.sounds` | Холостой ход, звуки по диапазонам скорости и интервалы проигрывания |
| `motorcycle.battery` | Ёмкость, расход и скорость зарядки |
| `motorcycle.storage` | Радиус уборки, длительность и отмена при уроне |
| `motorcycle.actionbar` | Интервал и тексты статуса движения, установки и уборки |
| `messages` | Все сообщения плагина в формате MiniMessage |

После изменения файла выполните:

```text
/moto reload
```

Перезагрузка обновляет конфигурацию мотоцикла. Для изменений, которые зависят от загрузки плагина или WorldGuard, предпочтительнее полный перезапуск сервера.

### Модель из ресурс-пака

По умолчанию предмет использует `BARRIER` и строку custom model data `base_bike`:

```yaml
motorcycle:
  item:
    material: BARRIER
    model: ""
    custom-model-data:
      strings: ["base_bike"]
```

Можно указать прямой item model:

```yaml
motorcycle:
  item:
    model: "my_pack:vehicles/gravibike"
```

Имена моделей и структура resource pack должны соответствовать формату Minecraft 1.21.x.

### Звуки из ресурс-пака

Звуковые события задаются их namespaced ID из `sounds.json` ресурс-пака:

```yaml
motorcycle:
  sounds:
    idle:
      sound: "quack_sound:s0"
    low:
      sound: "quack_sound:s1"
```

Плагин не поставляет аудиофайлы. Ресурс-пак клиента должен содержать событие и соответствующий `.ogg`-файл. Для отключения звуков установите `motorcycle.sounds.enabled: false`.

## WorldGuard

Если WorldGuard установлен, плагин регистрирует флаг:

```text
motorcycle-spawning
```

Флаг управляет разрешением появления сущностей, из которых состоит гравибайк, в регионе. По умолчанию состояние флага — `DENY`; чтобы разрешить появление в регионе, настройте его через WorldGuard:

```text
/rg flag <регион> motorcycle-spawning allow
```

Если WorldGuard отсутствует, эта интеграция не активируется. Зоны `no_ride` и `charge`, созданные командами плагина, работают независимо от WorldGuard.

## Хранение данных

Динамические данные зон хранятся в SQLite-файле:

```text
plugins/MotorcyclePlugin/database.db
```

При инициализации используется `PRAGMA journal_mode=WAL`. Зоны загружаются асинхронно, а операции сохранения и удаления выполняются через фоновый исполнитель, чтобы не блокировать основной поток сервера.

В старых версиях проекта зоны могли находиться в `zones.yml`. При обнаружении этого файла плагин импортирует его в SQLite и создаёт резервную копию `zones.yml.bak`. Новые зоны сохраняются только в базе данных.

## Сборка и тестирование

Для сборки требуется Maven и JDK 21:

```bash
mvn clean package
```

Результат:

```text
target/Motorcycle.jar
```

Компиляция production- и test-классов:

```bash
mvn test-compile
```

Запуск тестов:

```bash
mvn test
```

Основные зависимости проекта:

- Paper API `1.21.7-R0.1-SNAPSHOT` — `provided`.
- WorldGuard `7.0.14` — `provided`.
- JUnit Jupiter и Mockito — тесты.
- SQLite JDBC — тесты и локальные проверки хранилища.

## API для других плагинов

Плагин регистрирует Bukkit service `GravibikeDecalApi`. Его можно получить через `ServicesManager` и использовать для проверки предмета, изменения его внешнего вида или применения внешнего вида к ближайшему байку:

```java
public interface GravibikeDecalApi {
    boolean isGravibikeItem(ItemStack item);

    boolean applyToItem(ItemStack item, String skinId, String itemModel,
                        String customModelData);

    boolean applyToNearest(Player player, double radius, String skinId,
                           String itemModel, String customModelData);
}
```

Перед использованием API проверьте, что сервис зарегистрирован, так как он доступен только после успешного включения `MotorcyclePlugin`.
