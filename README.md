# Motorcycle Plugin

Paper-плагин для Minecraft 1.21.7, добавляющий электрический гравибайк: игрок устанавливает его предметом, управляет им и расходует заряд батареи. Администраторы могут задавать зоны запрета езды и зарядки.

## Требования и зависимости

- Java 21.
- Paper с API 1.21.7. Совместимость со Spigot или Purpur отдельно не заявлена.
- WorldGuard 7.0.14 или совместимый релиз — опционально; без него плагин работает без флага WorldGuard.
- Ресурс-пак нужен для пользовательской модели и собственных звуков, но не является зависимостью плагина.

## Установка и сборка

Поместите `Motorcycle.jar` в `plugins/` и запустите сервер. Плагин создаёт `config.yml` и SQLite-базу зон в `plugins/MotorcyclePlugin/`. WorldGuard можно установить отдельно. Для сборки из исходников с JDK 21 и Maven:

```bash
mvn clean package
```

Готовый файл: `target/Motorcycle.jar`.

## Использование

Предмет гравибайка устанавливается ПКМ. Для уборки подойдите к байку и нажмите клавишу смены рук (`F`), оставаясь неподвижным. Заряд расходуется при движении; неподвижный байк заряжается в зоне `charge`.

Основная команда `/moto`, алиас `/motorcycle`.

| Команда | Описание | Permission | По умолчанию |
|---|---|---|---|
| `/moto give <игрок> [количество]` | Выдать от 1 до 64 гравибайков | `motorcycle.give` | `op` |
| `/moto pos1` | Задать первую точку зоны | `motorcycle.admin` | `op` |
| `/moto pos2` | Задать вторую точку зоны | `motorcycle.admin` | `op` |
| `/moto zone create <no_ride\|charge> <имя>` | Создать зону по заданным точкам | `motorcycle.admin` | `op` |
| `/moto zone delete <имя>` | Удалить зону | `motorcycle.admin` | `op` |
| `/moto zone list` | Показать зоны | `motorcycle.admin` | `op` |
| `/moto reload` | Перезагрузить конфигурацию байка | `motorcycle.admin` | `op` |

Тип `no_ride` запрещает езду, `charge` заряжает стоящий байк. Для выбора области выполните `pos1` и `pos2` в одном мире. Имя зоны: латинские буквы, цифры, `_` или `-`, до 32 символов.

## Конфигурация

Файл: `plugins/MotorcyclePlugin/config.yml`. Настройки, которые обычно требуют подгонки:

- `motorcycle.item`: материал, MiniMessage-имя и lore предмета, `model`, `custom-model-data` и `custom-data` для ресурспака. Если задан `model`, выбор по custom model data не используется.
- `motorcycle.physics`: максимальная скорость, ускорение, торможение, поворот, прыжок и параметры парения/ступенек.
- `motorcycle.collision` и `motorcycle.visual`: габариты и смещения модели относительно сиденья.
- `motorcycle.water`, `motorcycle.particles`: движение по воде и эффекты поверхностей.
- `motorcycle.sounds`: звуки холостого хода и диапазонов скорости. ID событий должны быть определены в `sounds.json` клиентского ресурспака.
- `motorcycle.battery`: ёмкость, расход на максимальной скорости и скорость зарядки.
- `motorcycle.storage`: радиус и длительность уборки, отмена при получении урона.
- `motorcycle.actionbar` и `messages`: период обновления и тексты MiniMessage.

После изменения настроек выполните `/moto reload`.

## Данные и интеграции

Зоны хранятся в `plugins/MotorcyclePlugin/database.db` (SQLite, режим WAL). Если найдена старая база `zones.yml`, она импортируется; исходник сохраняется как `zones.yml.bak`.

При наличии WorldGuard регистрируется флаг `motorcycle-spawning`, управляющий появлением сущностей гравибайка в регионах.

Для других плагинов регистрируется Bukkit service `VLADMIX90.motorcyclePlugin.api.GravibikeDecalApi`. Интерфейс позволяет проверить предмет (`isGravibikeItem`), назначить ему внешний вид (`applyToItem`) или применить внешний вид к ближайшему байку (`applyToNearest`). Сервис доступен после включения этого плагина; PlaceholderAPI-интеграции нет.
